# PocketSmart AI 💰

PocketSmart AI is a simple Smart Budget & Recommendation Assistant.

## Features

- 🏠 Home Planner
- 🎉 Party Planner
- 💎 Jewelry Planner
- 💰 Budget-based recommendations
- 📱 Mobile-friendly interface
- 🚀 Runs directly in Termux
- 🐍 Python 3.14 compatible
- 📦 No external Python packages required

## Run on Termux

```bash
python app.py
